### Лабораторная 1: Простая анимация (Вариант 4)

**Аттрактор Лоренца** - двумерная визуализация классической системы дифференциальных уравнений,
демонстрирующей хаотическое поведение.

**Система уравнений:**
```
dx/dt = σ(y - x)
dy/dt = x(r - z) - y  
dz/dt = xy - b·z
```

где σ = 10, r = 28, b = 8/3 — классические параметры Лоренца.

**Функциональность:**
- Численная интеграция системы ОДУ методом Рунге-Кутты 4-го порядка
- 2D проекция (x-y плоскость) траектории в фазовом пространстве
- Интерактивные слайдеры для регулировки параметров σ, ρ, β в реальном времени
- Управление масштабом визуализации
- Отслеживание "бабочки" Лоренца - знаменитого аттрактора
- Функции сброса и очистки траектории

**Управление:**
- **σ (Sigma)** — число Прандтля, степень растяжения потока
- **ρ (Rho)** — число Рэлея, интенсивность конвекции
- **β (Beta)** — геометрический множитель
- **speed** — сколько шагов интегрирования делается за один кадр
- **scale** — масштаб изображения
- **Пауза (Space)** — остановить/продолжить анимацию
- **Сброс (R)** — перезапустить траекторию из начальной точки
- **Очистить (C)** — стереть след на холсте

### Лабораторная 2: Сложная анимация (Вариант 4)

**Ньютонов фрактал** - интерактивная визуализация метода Ньютона поиска корней
многочленов в комплексной плоскости.

**Полином:** f(z) = z³ - 1

**Описание:**
Каждый пиксель экрана представляет комплексное число. Для этого числа применяется
метод Ньютона:
```
z_{n+1} = z_n - f(z_n) / f'(z_n)
```

Цвет пикселя определяется:
1. Какому из трех корней сходится итерация (RGB компоненты)
2. Количеством итераций до сходимости (яркость)

Три корня (корни единицы третьей степени) окрашены:
- **Красный (255, 0, 0):** z = 1
- **Зеленый (0, 255, 0):** z = exp(2πi/3)
- **Синий (0, 0, 255):** z = exp(4πi/3)

**Функциональность:**
- Вычисление фрактала Ньютона для комплексной плоскости
- Красивая цветная визуализация с градиентом
- Интерактивное увеличение (зум) — щелчок на пиксель для приближения
- Регулировка количества итераций через слайдер
- Сброс представления к исходным границам
- Отображение статуса вычислений

**Управление:**
- **Левый клик на холсте** — увеличить область в точке клика в 2 раза
- **Клавиша R** или кнопка «Исходный вид» — вернуться к исходному виду
- **Слайдер «итераций»** — глубина прорисовки деталей (30–500)
- **Кнопка «Пересчитать»** — применить новые параметры
- **Кнопка «Сохранить PNG»** — сохранить текущее изображение

## Особенности реализации

### Архитектура

Проект следует принципам объектно-ориентированного программирования (ООП):

- **Разделение ответственности:** Модели, рендеры и UI компоненты разделены
- **Модульность:** Каждый класс имеет четкую зону ответственности
- **Расширяемость:** Легко добавить новые анимации и параметры

### Инкрементальная отрисовка

Рендерер ЛАБ1 не перерисовывает всю траекторию каждый кадр — он добавляет
на холст только новые сегменты, а самые старые удаляет при превышении лимита.
Это даёт стабильные ~60 кадров в секунду даже на длинной истории в 20 000 точек.

### Численная интеграция

Для ЛАБ1 используется метод **Рунге-Кутты 4-го порядка** (RK4):
```python
k1 = f(t, y)
k2 = f(t + h/2, y + h*k1/2)
k3 = f(t + h/2, y + h*k2/2)  
k4 = f(t + h, y + h*k3)
y(t+h) = y(t) + h/6 * (k1 + 2*k2 + 2*k3 + k4)
```

Это обеспечивает высокую точность при разумной вычислительной сложности.

### Фрактальные вычисления

Для ЛАБ2 реализована векторизованная обработка комплексной плоскости:
- Быстрое вычисление через NumPy операции
- Эффективное преобразование в RGB через Pillow
- Интерактивная масштабируемость
